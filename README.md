# La nuit des bandelettes

Un petit jeu d'arcade Halloween jouable dans le navigateur. Déplace le chasseur, repousse les momies et tente de survivre aux vagues.

## Jouer

Ouvre `index.html` dans un navigateur récent. Aucune installation n'est nécessaire.

- Déplacement : flèches ou ZQSD
- Tir : maintenir Espace
- Pause : Échap
- Sur mobile : utiliser les commandes tactiles affichées à l'écran

## Publier avec GitHub Pages

1. Crée un dépôt GitHub et envoie-y les fichiers de ce projet.
2. Dans le dépôt, ouvre **Settings > Pages**.
3. Dans **Build and deployment**, choisis **Deploy from a branch**, puis la branche `main` et le dossier `/(root)`.
4. Enregistre. GitHub Pages affichera l'adresse publique du jeu dans cette page après le déploiement.

Le fichier `index.html` est à la racine du dépôt, donc aucun outil de compilation n'est requis.
